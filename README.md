# جوار — إدارة ميزانية العمارة

تطبيق ويب (PWA) لإدارة الميزانية الشهرية والسنوية لعمارة سكنية: تحصيل الشقق، المصاريف، صندوق الطوارئ، حصة المصعد، التقارير (PDF + واتساب).

## التشغيل

- **على الجهاز:** شغّل خادمًا محليًا داخل المجلد ثم افتح `http://localhost:8000`:
  ```bash
  python -m http.server 8000
  ```
  (فتح `index.html` مباشرة بدون خادم يعمل، لكن بدون وضع عدم الاتصال ولا التثبيت.)
- **على عدة أجهزة:** انشر المجلد عبر GitHub Pages (Settings ← Pages ← Deploy from branch ← `main` / root)، ثم افتح الرابط من الجوال واختر "إضافة إلى الشاشة الرئيسية".

## البيانات

- كل البيانات محفوظة **محليًا في متصفح كل جهاز** (localStorage). لا يوجد خادم ولا مزامنة بين الأجهزة.
- انقل البيانات بين الأجهزة عبر: الإعدادات ← النسخ الاحتياطي (تصدير / استيراد).
- خذ نسخة احتياطية بانتظام: مسح بيانات المتصفح يحذف كل شيء.
- **لا اتصال بأي جهة خارجية:** الخط مضمَّن داخل التطبيق، ولا توجد خدمات ذكاء اصطناعي أو قراءة لجهات الاتصال. الاستثناء الوحيد: زر الإرسال عبر واتساب يفتح `wa.me` عند ضغطه فقط.

## صندوق الطوارئ والنقد

النقد في الحساب مقسوم لثلاث خانات مجموعها = النقد الفعلي: **متاح للصرف**، **صندوق الطوارئ**، **حصة المصعد**.
- فائض الشهر (بعد كل المصاريف وحصة المصعد): نسبة الصندوق (40% افتراضيًا) للصندوق، والباقي للمتاح.
- عجز الشهر: يُغطّى من المتاح أولًا، ثم من الصندوق إن لم يكفِ (ويظهر المبلغ المسحوب في السجل والتقارير).
- مصروف الطوارئ الفعلي يُصرف من الصندوق مباشرة.

## تحديث التطبيق

بعد أي تعديل على الملفات، ارفع رقم `CACHE_VERSION` في `sw.js` (مثلًا من `jiwar-v15` إلى `jiwar-v16`) حتى تستلم الأجهزة المثبّتة النسخة الجديدة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا |
| `sw.js` | Service Worker: العمل بدون إنترنت والتحديث |
| `manifest.json` | بيانات التثبيت كتطبيق |
| `icons/`, `favicon.ico` | الأيقونات وشاشات البداية |
| `fonts/` | خط Cairo (ترخيص SIL OFL في `fonts/OFL.txt`) |
